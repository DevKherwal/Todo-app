# To-Do App

A simple to-do list app I built while learning web development. You can add tasks, mark them as done, and delete them. Tasks stay saved even after you refresh the page.

## Features
- Add new tasks
- Click a task to mark it as done
- Delete tasks
- Saved in the browser with localStorage

## Built with
HTML, CSS (Flexbox) and JavaScript

## Live demo
https://devkherwal.github.io/Todo-app/

This is my first full project. I learned how to create elements with JavaScript, handle forms, use localStorage, and track my work with Git and GitHub.
